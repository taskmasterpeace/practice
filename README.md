# Practice

Caribbean Map Quest: seven tap-and-drag games for learning 9 Caribbean and Central American countries (Cuba, Jamaica, Dominican Republic, Guatemala, El Salvador, Honduras, Nicaragua, Costa Rica, Panama). Built for iPad.

Single static page (`index.html`). Map outlines from Natural Earth via world-atlas; flags from flag-icons (MIT).
Source/build scripts live in `D:/git/caribbean-map-quest/` (gen.mjs → map.json, build.mjs → index.html).
