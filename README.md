# Practice

Homework Branch (first called Map Quest): tap-and-drag geography practice with read-aloud voice. Four lessons: Caribbean and Central America (9 countries), North America (3 countries, 3 oceans), U.S. mountains and rivers, and The 50 States (find, label, flags, shapes, spelling, capitals and regions). Built for iPad, works on a phone.

Single static page () plus Miss Ruth voice clips in . Nothing is fetched from anywhere else while playing: fonts, maps and flags are inside the page, and stars and badges are saved on the device only.

Sources: country outlines from Natural Earth via world-atlas; country flags from flag-icons (MIT); state shapes, names, postal codes and regions from the U.S. Census Bureau (public domain); state capitals from Wikidata (CC0); state flags from Wikimedia Commons, public-domain files only (Mississippi is left out because its file is not marked public domain); fonts Baloo 2 and Nunito (SIL Open Font License).
