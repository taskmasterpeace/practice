# Practice

Map Quest: tap-and-drag geography practice with read-aloud voice. Three lessons: Caribbean and Central America (9 countries), North America (3 countries, 3 oceans), and U.S. mountains and rivers (Rockies, Appalachians, Mississippi, Rio Grande, James, Great Lakes). Built for iPad.

Single static page (`index.html`). Map outlines from Natural Earth via world-atlas; flags from flag-icons (MIT).
Source/build scripts live in `D:/git/caribbean-map-quest/` (gen.mjs + gen2.mjs → map data, build2.mjs → index.html).
